## Key Learnings :point_down:
- Login and system documentation
  We can log into Linux two ways.
  1. Local - Through VM
  2. Remote - We can find the ip address of our remote linux machine and connect in using Remote Desktop Connection
- Sections in Linux commands
  (I just found this while I am doing the quiz)
  There are 8 sections.
    1. User Commands
    2. System Calls
    3. Library Calls
    4. Special Files/ Devices
    5. File Formats / Configuration
    6. Games / Entertainment
    7. Miscellaneous / Conventions
    8. System Administration / Super User Commands
    9. Kernel Routines (Less Common)
  For an example, If we type **man 8 useradd** it means, this is a system administration version not a regular user command.
- File and Directories
    **cd /** - take you to the root directory
    **cd -** - go to previous directory
    **cd** - go to home directory

    **touch** - creating files
    **mkdir** - make directory
    **cp** - copy
    **cp -r** - copy recursively
    **mv** - move
    **rm** - remove
