# Shell Scripting for DevOps - Part 2

## Objective

Create a custom shell script to monitor the health of a Linux node (VM).

Example scenario:

- A server reports an issue.
- Download the health-check script.
- Execute the script.
- Analyze the output.

---

## Create the Script

```bash
vi nodehealth.sh
```
