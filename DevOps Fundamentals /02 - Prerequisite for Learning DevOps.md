## Jira Project Management

### Jira Workflow

```text
Organization
    ↓
Project
    ↓
Product Owner
    ↓
Epic
    ↓
Stories
    ↓
Assigned to Developers
```

### Getting Started with Jira Cloud

1. Create an Atlassian account.
2. Log in to Jira Cloud.
3. Create an Organization.
4. Create a Project.
5. Create Epics.
6. Create User Stories under each Epic.
7. Assign stories to developers.

# Scrum

Scrum is an Agile framework used to manage software development projects.

## Sprint

- Sprint duration: **2–3 weeks**
- Team works on assigned stories.
- At the end of the sprint:
  - Sprint Review
  - Sprint Retrospective
  - Track completed and remaining work

---

# Common Project Roles

| Role | Responsibility |
|------|----------------|
| Business Analyst | Gather and document customer requirements. |
| Product Manager | Define product vision, goals, and priorities. |
| Product Owner | Manage the product backlog and create user stories. |
| UI/UX Designer | Design the user interface and user experience. |
| Software Architect | Design the system architecture (HLD & LLD). |
| Developer | Build the application (Frontend, Backend, APIs). |
| DBA | Design and manage databases. |
| QA Engineer | Test software quality and functionality. |
| Security Engineer | Ensure application and infrastructure security. |
| DevOps Engineer | Build CI/CD pipelines and manage infrastructure. |
| Release Manager | Plan and manage software releases. |
| SRE | Maintain system reliability, availability, and performance. |
| Technical Writer | Create technical documentation. |

---

# DevOps Engineer Responsibilities

- Build CI/CD pipelines
- Automate software deployment
- Manage development and production environments
- Monitor applications
- Create dashboards and metrics
- Configure alerts and notifications
- Improve deployment speed
- Reduce manual work

---

# Product Monitoring

After the application is deployed:

- Monitor application health
- Check availability
- Measure performance
- Create dashboards
- Track metrics
- Configure alerts
- Notify developers when issues occur

# Key Terms

| Term | Meaning |
|------|---------|
| Epic | A large feature that contains multiple stories. |
| Story | A small piece of work assigned to a developer. |
| Sprint | A fixed period (2–3 weeks) to complete planned work. |
| Backlog | A prioritized list of work items. |
| CI | Continuous Integration. |
| CD | Continuous Delivery / Deployment. |
| HLD | High-Level Design. |
| LLD | Low-Level Design. |
| SRE | Site Reliability Engineering. |
